# Double V Business Support Services — Static Website

A modern, responsive, static website for Double V Business Support Services built with **Next.js 14**, **TypeScript**, **Tailwind CSS**, and **Lucide Icons**.

---

## 🎨 Brand Identity
- **Colors**: Navy `#0B0E54` · Blue `#1A3A8F` · Royal `#2B4FC7` · Silver `#C0C8D8` · Dark `#060728`
- **Fonts**: Bebas Neue (headings) · Montserrat (body)

---

## 🛠 Tech Stack

| Layer | Technology |
|---|---|
| Framework | Next.js 14 (App Router) |
| Language | TypeScript |
| Styling | Tailwind CSS |
| Forms | React Hook Form + Zod |
| Icons | Lucide React |
| Deployment | Vercel / Netlify / GitHub Pages / Any Static Host |

---

## 🚀 How to Run

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```

## 🌐 Pages & Sections

| Route / Section | Description |
|---|---|
| `/` | Main homepage featuring Hero, Services, Rates, Certifications, Contact, Location Map |
| `/#services` | Comprehensive business support services overview |
| `/#rates` | Transparent pricing plans and à la carte service rates |
| `/#certifications` | Accredited certifications (SEC, BIR, IPOPHL, PICPA, PRC, BPLO) & awards |
| `/#contact` | Contact form & office details |
| `/#location` | Interactive Google Maps location & office hours |
| `/privacy` | Privacy Policy page |
| `/terms` | Terms of Service page |
